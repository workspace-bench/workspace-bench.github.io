Evaluation

评测流程与规则（占位）。建议在发布时把这里替换为与你们 harness 完全一致的文字说明，并提供可执行命令。

What We Measure

File Collaboration

多文件一致性修改、跨模块依赖处理、冲突解决与回归风险控制。

Tool Use

检索、定位、编辑、测试、回滚等工具链在真实项目中的协作表现。

Reproducibility

是否提供足够材料让第三方复现实验并得到一致结果。

Robustness

在噪声、部分信息缺失与多轮修改下的稳定性。

Environment

建议明确以下约束：
OS / Kernel Container runtime CPU / GPU Python / Node / Java versions Repository checkout strategy Network policy Time / token / cost limits

Scoring

Success Rate

任务级通过率（单任务通过 = 补丁应用成功 + 测试通过 + 规则满足）。

Cost / Latency

可选：按任务平均成本、耗时与交互轮数等维度展示。

Safety

可选：文件修改范围、危险命令与敏感信息处理的合规性。

Checked

维护者复核后展示 ✅（可选：复核等级与说明）。
