Docs

这里是 RIP-Bench 的评测说明页（占位）。你可以直接把论文/仓库的链接与具体参数替换进来。

Quickstart

1. 获取数据

下载任务集合、仓库快照与评测配置。

2. 运行评测

使用统一 harness，在隔离环境中复现执行。

3. 生成结果

输出 JSON/日志/补丁文件，并进行一致性校验。

4. 提交上榜

提交元信息与可复现实验材料，通过后进入公开榜单。

Result Schema

Leaderboard 页目前使用以下字段渲染（你可以在渲染脚本里扩展更多列）：
name: string resolved: number date: string (YYYY-MM-DD) logo: string[] (可选) tags: string[] (可选，建议包含 "Org: xxx") site: string | string[] (可选) checked: boolean (可选)

Submission

必需材料

结果 JSON、模型与 Agent 配置、运行环境信息与版本号。

推荐材料

完整日志、复现实验脚本、运行录屏与失败案例分析。

Checked 标记

提交可复现实验材料并通过维护者复核后，展示 ✅。

联系维护者

如需加速审核，推荐在 issue 中附上复现实验指令。
